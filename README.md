# Лендинг кофейни

Многостраничный лендинг: главная, о нас, блог, контакты.

**Стек:** HTML · CSS · JavaScript

## Что внутри

- `index.html`, `about.html`, `blog.html`, `contacts.html` — страницы
- `css/` — стили
- `js/` — скрипты
- `images/` — графика
- `docs/` — материалы по проекту

## Запуск

Открыть `index.html` в браузере — сборка не нужна.
